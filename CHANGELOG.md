# Changelog

User-facing changes to TabletKey.

## 0.1.0

### Added

- Standalone pen input for the VEIKK Voila VO1060 on COSMIC Linux, without an OpenTabletDriver dependency.
- Visual mappings for the four tablet keys, dial button, and scroll wheel, with live control highlighting.
- Monitor selection, tablet rotation, and a draggable active writing area.
- Adjustable pressure response with Light touch, comfortable-peak calibration, and live sensor/output graphs.
- Hover/contact diagnostics showing range exits and report timeouts.
- A background driver with start, status, stop, and tablet reconnection support.
